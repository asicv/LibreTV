# FAQ

## 部署相关

**Q: 打开站点一直提示"需要配置密码"？**
服务器未设置 `PASSWORD` 环境变量。Docker 部署检查 `.env`；手动部署确认启动命令中带 `PASSWORD=...`。设置后需重启服务。

**Q: 登录后刷新又要求输入密码？**
- 生产环境（HTTPS）下 Cookie 为 `Secure`，用 HTTP 访问生产构建会导致 Cookie 无法保存——请配置 HTTPS 或以开发模式运行；
- 多实例部署未设置 `PROXY_SECRET`：各实例派生密钥不同，会话互不认账。

**Q: 忘记密码怎么办？**
修改 `PASSWORD` 环境变量并重启。旧会话立即全部失效（密钥随之改变）。

## 搜索相关

**Q: 搜索提示"请先添加数据源" / "尚未勾选数据源"？**
本项目不内置采集站。到「设置 → 数据源」添加 Apple CMS 采集站地址并勾选。

**Q: 某个源一直搜索失败？**
结果区顶部会列出失败源名称。直接浏览器访问 `{api}?ac=videolist&wd=test` 判断是源挂了还是网络不通；不用的源可以取消勾选或删除。

**Q: 搜索结果为什么按名称排序？**
跨源聚合后按影片名（zh-CN locale）排序、同名片按源名排序，便于对比同一影片在不同源的画质/集数。

**Q: 从播放页返回搜索页会重新搜索吗？**
通常不会。客户端缓存搜索结果 5 分钟、服务端缓存同一关键词+源组合的结果 60 秒：返回时直接呈现缓存，不重复请求上游。需要强制刷新时重新提交一次搜索即可。

**Q: 详情为什么有缓存？会不会导致新剧集看不到？**
详情接口有 60 秒服务端缓存（同一影片 + 同一源），用于换源测速等场景避免重复打上游。剧集更新以源站为准，60 秒后即取到最新。

## 播放相关

**Q: 视频一直"正在加载"？**
按顺序尝试：① 点「切换资源」换其他源；② 设置中切换封面/直连相关配置确认网络；③ 该源分片可能仅允许特定地区/Referer，代理回退通常能自动解决，若仍失败请换源。

**Q: 出现"直连失败，改用代理重试"后播放正常，但快进卡顿？**
代理播放的带宽受限于服务器。属预期行为，建议优先寻找可直连的源。

**Q: 自动跳到下一集后从头播放了？**
确认「自动连播」开关已打开（播放页操作栏或设置中）。

**Q: 换源后集数对不上？**
换源按集数索引对齐，目标源集数少于当前集数时会回到第 1 集。

## 数据相关

**Q: 换浏览器/设备后历史和进度还在吗？**
不在。历史与进度保存在本机 IndexedDB，不上传服务器。可用「设置 → 导出配置」手动迁移。

**Q: 观看历史里某条记录播放时提示"数据源不存在"？**
该记录的来源源已被删除。重新在设置中添加同名 API 地址（key 一致即可恢复），或删除该历史。

**Q: IndexedDB 数据会占多少空间？**
仅存定位信息（不含全集 URL），100 条历史通常 < 100KB。

## 安全相关

**Q: 密码是明文传输吗？**
登录请求把密码放在 POST body 中，生产环境务必启用 HTTPS 防止传输层被窃听。

**Q: 代理会被滥用吗？**
代理需要登录会话；未登录仅放行图片类目标且同样受 SSRF 校验约束。公网部署建议在反代层再加 IP 级限流。

**Q: 为什么不给站点加注册/多用户？**
LibreTV 定位为轻量自托管工具，单密码门禁 + 本机数据即可满足场景；多用户会引入服务端存储与隐私复杂度。
